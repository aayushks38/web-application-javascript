# WAF Lab Assignment 3 - JavaScript Programming

This repository contains 20 JavaScript programming assignments covering fundamental JavaScript concepts, DOM manipulation, and event handling.

## 📋 Assignment List

### Basic JavaScript Concepts (1-4)
1. **Variables & Data Types** - Declare and display different data types
2. **Arithmetic Operations** - Perform basic math operations using functions
3. **Rectangle Calculator** - Calculate area and perimeter
4. **Temperature Converter** - Convert between Celsius and Fahrenheit

### Conditional Statements (5-6)
5. **Even or Odd Checker** - Determine if a number is even or odd
6. **Largest of Three** - Find the largest among three numbers

### Loops (7-12)
7. **Factorial Calculator** - Calculate factorial using loops
8. **Multiplication Table** - Generate multiplication tables
9. **Sum of Natural Numbers** - Calculate sum of first N numbers
10. **Prime Number Checker** - Check if a number is prime
11. **Count Digits** - Count digits in a number using while loop
12. **Reverse Number** - Reverse the digits of a number

### Switch Statement (13-14)
13. **Calculator with Switch** - Simple calculator using switch statement
14. **Student Grade Calculator** - Calculate total, average, percentage, and grade

### DOM Manipulation (15-20)
15. **Dynamic Text Change** - Change HTML element text dynamically
16. **Background Color Changer** - Change page background color
17. **Form Input Display** - Accept and display form input
18. **Counter App** - Increment, decrement, and reset counter
19. **Even & Odd Display** - Display even and odd numbers in a range
20. **Web Calculator** - Full-featured web calculator

## 🚀 Getting Started

### Prerequisites
- Any modern web browser (Chrome, Firefox, Safari, Edge)
- A text editor (VS Code, Sublime Text, etc.)

### Installation
1. Clone this repository:
   ```bash
   git clone https://github.com/aayushks38/web-application-javascript.git
   ```

2. Navigate to the project directory:
   ```bash
   cd web-application-javascript
   ```

3. Open `index.html` in your web browser

### Usage
Simply open `index.html` in any web browser. The main page displays all 20 assignments as clickable cards. Click on any assignment to view and interact with it.

## 📝 Assignment Details

Each assignment demonstrates specific JavaScript concepts:

- **Functions**: Reusable code blocks for calculations
